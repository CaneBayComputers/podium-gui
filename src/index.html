About Podium

                ×
            

            

                

                    
Podium

                    Version 1.0 Beta 4
                

                
Professional PHP Development Platform

                
Podium is a comprehensive Docker-based development environment for PHP projects, featuring both a powerful Command Line Interface (CLI) and an intuitive Graphical User Interface (GUI).

                
                

                    
Features:

                    
    
                        
  • 🚀 Multi-project support with isolated environments
    • 
                        
  • 🗄️ Integrated database services (MySQL, PostgreSQL, MongoDB)
    • 
                        
  • ⚡ Caching solutions (Redis, Memcached)
    • 
                        
  • 📧 Email testing with MailHog
    • 
                        
  • 🤖 Local AI integration with Ollama
    • 
                        
  • 🌐 Instant LAN sharing for demos
    • 
                        
  • 🎨 Modern GUI with retro synthwave theme
    •

❓ Help & CLI Commands

                    
                

                

                    

                        

                            
🖥️ GUI Features

                            
    
                                
  • Create Projects: Use the "+ New Project" button to create Laravel, WordPress, or PHP projects
    • 
                                
  • Clone Projects: Use the "📥 Clone" button to clone existing Git repositories
    • 
                                
  • Manage Services: Start/stop shared services like Redis, MariaDB, and PostgreSQL
    • 
                                
  • Project Status: View real-time status of all your projects
    • 
                                
  • LAN Access: Click project URLs to open them in your browser
    • 
                            

                        

                        
                        

                            
⌨️ Podium CLI Commands

                            
You also have full command-line access via the podium command:

                            
                            

                                
🚀 Project Management

                                

                                    podium new my-project
                                    Create a new project interactively
                                

                                

                                    podium status
                                    Show status of all projects
                                

                                

                                    podium up [project]
                                    Start project containers
                                

                                

                                    podium down [project]
                                    Stop project containers
                                

                            

                            
                            

                                
🛠️ Development Tools (from project directory)

                                

                                    podium composer install
                                    Run Composer inside container
                                

                                

                                    podium art migrate
                                    Run Laravel Artisan commands
                                

                                

                                    podium wp plugin list
                                    Run WP-CLI commands
                                

                                

                                    podium exec 'ls -la'
                                    Execute commands in project container
                                

                            

                            
                            

                                
🔧 System Management

                                

                                    podium configure
                                    Configure Podium environment
                                

                                

                                    podium start-services
                                    Start shared services
                                

                                

                                    podium stop-services
                                    Stop shared services
                                

                            

                        

                        
                        

                            
📚 More Information

                            
    
                                
  • Run podium help in terminal for complete command reference
    • 
                                
  • Use --json-output flag for automation and scripting
    • 
                                
  • All development tools require being in a project directory
    • 
                                
  • Projects are accessible via LAN for team demos and testing
